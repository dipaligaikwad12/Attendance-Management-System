
# Online Student Attendance Management System

A beginner-friendly web application for managing student records
and recording daily attendance using PHP and MySQL.

## Features

- Add students 
- View all registered students
- Mark attendance as Present or Absent
- View attendance records by date
- Display present, absent, and unmarked student counts
- Delete student records
- Download Attendance record in excel format

## Technologies Used

- HTML5
- CSS
- PHP
- MySQL
- XAMPP

## Requirements

- XAMPP
- Web browser
- Code editor (optional)

## Installation

1. Copy the project folder into XAMPP's `htdocs` directory.
2. Start Apache and MySQL in XAMPP.
3. Open `http://localhost/phpmyadmin`.
4. Import the `database.sql` file.
5. Open `http://localhost/Attendance-Management-System/Student/`.
